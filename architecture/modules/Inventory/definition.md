# Module: Inventory
**Layer:** Domain + Logic (downstream)
**Responsibility:** Warehouse, locations, transfers and stock moves, stock levels, counts and reorder rules — plus the order-fulfilment bridge.

_Generated by `pipelines/odoo/arch_blueprint.py` from the confirmed BRDs; edit brd_spec.py / brd_content.py / ui_spec.py._

## Entities

| Entity | Persistent? | Key attributes | Notes |
|---|---|---|---|
| Warehouse | yes | Name, ShortName, Active | reception_steps / delivery_steps fixed to one step; no routes/rules. |
| Location | yes | Name, FullName, LocationType, Barcode, Active | A physical or virtual place stock moves from/to (WH/Stock, Vendors, Customers, Inventory adjustment). |
| OperationType | yes | Name, Kind, SequenceCode, CreateBackorder, Active | Receipts, Delivery orders, Internal transfers: numbering and default locations. |
| Transfer | yes | Number, Status, ScheduledDate, DateDone, Deadline, SourceDocument | A receipt, delivery or internal transfer grouping stock moves. |
| StockMove | yes | Description, Status, Date, DemandQuantity, Quantity, Picked | Movement of one product quantity between two locations (stock.move.line merged in). |
| StockLevel | yes | Quantity, ReservedQuantity, CountedQuantity, CountSet, ScheduledCountDate, IncomingDate | No lots, packages or owners: one row per product × location. |
| ReorderRule | yes | Name, MinQuantity, MaxQuantity, QuantityMultiple, Automatic, Active | Min/max replenishment rule: below minimum, create an RFQ up to maximum. |
| ValidateTransferRequest | no (non-persistent) | CreateBackorder | Wizard data: validate a transfer with less than the demand — create a backorder or not. |
| StockOnHand | view entity (OQL) | — | Per product: on hand, reserved, incoming and outgoing quantities (forecast). (replaces report.stock.quantity) |

## Key microflows

| Microflow | Kind | Purpose |
|---|---|---|
| ACT_Transfer_Confirm | ACT | Draft -> Waiting; try to reserve. |
| ACT_Transfer_CheckAvailability | ACT | Reserve stock for outgoing moves from internal locations; incoming moves are always Ready. |
| ACT_Transfer_Validate | ACT | Validate: if any move short -> open backorder popup; else complete. |
| SUB_Transfer_Done | SUB | Apply moves to StockLevel (source -, destination +), set Done and date; optional backorder; update order quantities. |
| ACT_Transfer_Cancel | ACT | Unreserve and cancel. |
| ACT_StockLevel_ApplyCount | ACT | Create adjustment moves for counted quantities and clear the count. |
| SCE_ReorderRules_Run | SCE | Scheduled: evaluate automatic rules and create/extend RFQs. |
| SUB_ReorderRule_Replenish | SUB | One rule: compute qty to order and add it to an RFQ for the vendor. |
| SUB_SalesOrder_CreateDelivery | SUB | Create and confirm the delivery for goods lines not yet covered by moves. |
| SUB_PurchaseOrder_CreateReceipt | SUB | Create the receipt for goods lines. |
