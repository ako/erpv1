# Module: Core
**Layer:** Common
**Responsibility:** Shared kernel: the company, its currency and countries, taxes, payment terms and document numbering.

_Generated by `pipelines/odoo/arch_blueprint.py` from the confirmed BRDs; edit brd_spec.py / brd_content.py / ui_spec.py._

## Entities

| Entity | Persistent? | Key attributes | Notes |
|---|---|---|---|
| Company | yes | Name, Email, Phone, Street, Street2, Zip | Singleton (multi-company out of scope). Odoo keeps the address on a linked res.partner; flattened here. |
| Country | yes | Name, Code | Countries for addresses. |
| Currency | yes | Name, Symbol, Rounding, DecimalPlaces, SymbolPosition, Active | Currency of the company and its documents. |
| Sequence | yes | Code, Prefix, Padding, NextNumber | ir.sequence is a framework model (C12); kept as a tiny Mendix entity because every document needs a readable number. |
| Tax | yes | Name, Scope, Computation, Amount, IncludedInPrice, LabelOnInvoice | No tax groups, repartition lines, fiscal positions or cash basis. |
| PaymentTerm | yes | Name, Note, Sequence, Active | Early-payment discounts dropped. |
| PaymentTermLine | yes | Value, ValueAmount, Days, DelayType | One instalment: percent or fixed amount, due N days after a reference date. |
| LineAmounts | no (non-persistent) | Subtotal, TaxAmount, Total | new: helper for SUB_Tax_ComputeLine |

## Key microflows

| Microflow | Kind | Purpose |
|---|---|---|
| SUB_Sequence_NextNumber | SUB | Lock the sequence row, format prefix (year substitution) + zero-padded number, increment. |
| ASU_Core_SeedData | ASU | After-startup: create company, currency, countries, sequences, UoMs, locations, operation types if missing. |
| SUB_Tax_ComputeLine | SUB | For a price, quantity, discount and taxes: base, tax amount, total (price-included taxes extracted first). |
| SUB_PaymentTerm_ComputeDueDate | SUB | Due date of the last instalment from invoice date and term lines. |
