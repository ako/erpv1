# Module: Sales
**Layer:** Domain + Logic
**Responsibility:** Quotations to sales orders, quotation templates, sales teams and sales analysis.

_Generated by `pipelines/odoo/arch_blueprint.py` from the confirmed BRDs; edit brd_spec.py / brd_content.py / ui_spec.py._

## Entities

| Entity | Persistent? | Key attributes | Notes |
|---|---|---|---|
| SalesTeam | yes | Name, InvoicingTarget, Active | Sales team with a leader and members (reporting, default on orders). |
| SalesOrder | yes | Number, Status, Locked, OrderDate, ExpirationDate, DeliveryDate | A quotation that becomes a confirmed sales order. |
| SalesOrderLine | yes | Sequence, LineType, Description, Quantity, UnitPrice, DiscountPercent | A product, section or note line of a sales order. |
| QuotationTemplate | yes | Name, ValidityDays, TermsAndConditions, Active | Reusable quotation: default lines, validity and terms. |
| QuotationTemplateLine | yes | Sequence, LineType, Description, Quantity | A default line of a quotation template. |
| CreateInvoiceRequest | no (non-persistent) | ConsolidatePerCustomer | Regular invoices only; down payments (advance_payment_method=percentage/fixed) dropped. |
| SalesAnalysis | view entity (OQL) | — | Order lines joined to order, customer, product, salesperson: amounts and quantities for pivots/charts. (replaces sale.report) |

## Key microflows

| Microflow | Kind | Purpose |
|---|---|---|
| ACT_SalesOrder_New | ACT | Create a quotation with company defaults; on customer change fill addresses, pricelist, payment term, salesperson. |
| ACT_SalesOrder_ApplyTemplate | ACT | Replace lines by the template lines; set expiration = today + template validity. |
| ACT_SalesOrderLine_ChangeProduct | ACT | Default description, unit, taxes and pricelist price for a new product on a line. |
| SUB_SalesOrder_RecomputeTotals | SUB | Per line subtotal/tax/total (discount, taxes incl./excl.), then order totals. |
| ACT_SalesOrder_MarkSent | ACT | Status Quotation -> QuotationSent. |
| ACT_SalesOrder_Confirm | ACT | Validate and confirm; set order date; launch delivery (F007); recompute statuses. |
| ACT_SalesOrder_Cancel | ACT | Cancel open transfers and the order. |
| ACT_SalesOrder_SetToQuotation | ACT | Cancelled -> Quotation. |
| ACT_SalesOrder_ToggleLock | ACT | Lock/unlock a confirmed order. |
| SUB_SalesOrder_UpdateInvoiceStatus | SUB | Per line qty to invoice (by product invoice policy) -> order InvoiceStatus. |
| SUB_SalesOrder_UpdateDelivered | SUB | Recompute delivered quantities and delivery status from done moves. |
