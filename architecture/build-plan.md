Default applied: a row is one BRD use case. Shared logic used across use cases gets its own row per module. 66 BUILD rows for 49 use cases (1.35).

## 4. Scope boundary

- **In scope, real:** F001–F008 as confirmed (C1–C8).

- **Out of scope:** C9–C12; mail/portal/payment/EDI/barcodes; variants, lots, packages, multi-step routes, ledger, PDFs, returns, scrap, down payments (Stage 0/2 decisions).
